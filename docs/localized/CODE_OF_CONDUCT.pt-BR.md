# Código de conduta

[English](../../CODE_OF_CONDUCT.md) · [Português](CODE_OF_CONDUCT.pt-BR.md) · [Español](CODE_OF_CONDUCT.es.md)

## Escopo e comportamento esperado

Todos os participantes de issues, PRs, reviews, discussions e comunicação relacionada ao projeto devem ser respeitosos, pacientes e tecnicamente honestos. Acolher iniciantes e os três idiomas; corrigir construtivamente sem humilhar, respeitar privacidade e autoria e distinguir fatos de incerteza.

## Comportamento inaceitável

Assédio, ameaças, perseguição, discriminação, ódio, assédio sexualizado, ataques pessoais, hostilidade a iniciantes, personificação, plágio, exposição de dados, exigência de informação privada, contribuições maliciosas, fabricação intencional e retaliação são proibidos. Discordância é bem-vinda quando focada no trabalho, não na pessoa.

## Relato e confidencialidade

Usar método de contato privado publicado voluntariamente pelo [mantenedor](https://github.com/RamonRDR), se disponível. Caso contrário usar [pedido de contato privado](https://github.com/RamonRDR/git-study-guide/issues/new?template=private-contact-request.pt-BR.md) apenas para solicitar canal; a issue é PÚBLICA. Não incluir nomes, detalhes do incidente, evidências, prints, dados de contato ou outras informações sensíveis. Se até o pedido público expuser alguém, não postar; usar ferramentas de denúncia do GitHub para abuso. No eventual canal privado compartilhar só contexto e evidência relevantes. Confidencialidade por melhor esforço, não absoluta.

## Aplicação

O mantenedor avalia contexto, impacto, repetição e segurança. Medidas proporcionais podem incluir esclarecimento, remoção de material nocivo, advertência, restrição temporária, exclusão permanente ou escalonamento ao GitHub ou autoridades competentes. Relatos incompletos de boa-fé não são punidos; denúncias abusivas intencionais e retaliação podem violar a política. Se o mantenedor estiver implicado, usar denúncia independente do GitHub em vez de depender só dele. Sem prazo de resposta garantido.
