# Política de seguridad

[English](../../SECURITY.md) · [Português](SECURITY.pt-BR.md) · [Español](SECURITY.es.md)

## Alcance

Este es un repositorio educativo, no servicio desplegado. Correcciones de seguridad se aplican a main actual y última release mantenida si existe. Commits históricos, forks y herramientas de terceros no se mantienen aquí. Riesgos relevantes incluyen workflows inseguros, credenciales expuestas, ejemplos comprometidos y orientación insegura reproducible. Errores ordinarios de contenido van a issues normales.

## Denuncia privada

Si la pestaña Security ofrece **Report a vulnerability**, usarla para un informe privado. Su disponibilidad no se ha verificado; no suponer que está habilitada. De lo contrario usar método privado publicado por el [mantenedor](https://github.com/RamonRDR) o [solicitud de contacto privado](https://github.com/RamonRDR/git-study-guide/issues/new?template=private-contact-request.es.md) únicamente para establecer canal. La issue es PÚBLICA: nunca incluir detalles, pasos de explotación, archivos afectados, capturas, secretos ni datos personales/de contacto. Si la solicitud misma implica exposición, no publicar. No se garantiza alternativa privada verificada hasta que el mantenedor proporcione canal.

## Informe seguro y respuesta

Tras establecer canal privado, informar revisión/componente, impacto, reproducción mínima segura, entorno y mitigación si se conoce; nunca credenciales reales ni datos no autorizados. Investigar solo en entornos desechables autorizados: sin interrupción, robo de credenciales, ingeniería social, acceso a datos ajenos ni pruebas destructivas. Mantenedor hará triaje de mejor esfuerzo, coordinará corrección y divulgación responsable y acreditará informantes cuando se solicite y sea seguro. Sin SLA, bounty ni recompensa prometida. No divulgar detalles explotables públicamente mientras esté pendiente la corrección.
