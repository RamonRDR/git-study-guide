# Política de segurança

[English](../../SECURITY.md) · [Português](SECURITY.pt-BR.md) · [Español](SECURITY.es.md)

## Escopo

Este é um repositório educacional, não serviço implantado. Correções de segurança miram main atual e última release mantida se existir. Commits históricos, forks e ferramentas de terceiros não são mantidos aqui. Riscos relevantes incluem workflows inseguros, credenciais expostas, exemplos comprometidos e orientações inseguras reproduzíveis. Erros comuns de conteúdo vão para issues normais.

## Relato privado

Se a aba Security oferecer **Report a vulnerability**, usar para relato privado. A disponibilidade não foi verificada; não presumir habilitação. Caso contrário usar método privado publicado pelo [mantenedor](https://github.com/RamonRDR) ou [pedido de contato privado](https://github.com/RamonRDR/git-study-guide/issues/new?template=private-contact-request.pt-BR.md) exclusivamente para estabelecer canal. A issue é PÚBLICA: nunca incluir detalhes, passos de exploração, arquivos afetados, prints, segredos ou dados pessoais/de contato. Se o próprio pedido arriscar exposição, não postar. Nenhum fallback privado verificado é garantido até o mantenedor fornecer canal.

## Relato seguro e resposta

Após estabelecer canal privado, informar revisão/componente, impacto, reprodução mínima segura, ambiente e mitigação se conhecida; nunca credenciais reais ou dados não autorizados. Pesquisar somente em ambientes descartáveis autorizados: sem interrupção, roubo de credenciais, engenharia social, acesso a dados alheios ou testes destrutivos. Mantenedor fará triagem por melhor esforço, coordenará correção e divulgação responsável, e creditará relatores quando solicitado e seguro. Sem SLA, bounty ou recompensa prometida. Não divulgar detalhes exploráveis publicamente enquanto correção pendente.
