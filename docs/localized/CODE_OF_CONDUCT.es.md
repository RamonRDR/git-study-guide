# Código de conducta

[English](../../CODE_OF_CONDUCT.md) · [Português](CODE_OF_CONDUCT.pt-BR.md) · [Español](CODE_OF_CONDUCT.es.md)

## Alcance y conducta esperada

Todos los participantes de issues, PR, reviews, discussions y comunicación relacionada con el proyecto deben ser respetuosos, pacientes y técnicamente honestos. Acoger principiantes y los tres idiomas; corregir constructivamente sin humillar, respetar privacidad y autoría y distinguir hechos de incertidumbre.

## Conducta inaceptable

Acoso, amenazas, persecución, discriminación, odio, acoso sexualizado, ataques personales, hostilidad hacia principiantes, suplantación, plagio, exposición de datos, exigencia de información privada, contribuciones maliciosas, fabricación intencional y represalias están prohibidos. El desacuerdo es bienvenido si se centra en el trabajo, no en la persona.

## Denuncia y confidencialidad

Usar un método de contacto privado publicado voluntariamente por el [mantenedor](https://github.com/RamonRDR), si está disponible. De lo contrario usar [solicitud de contacto privado](https://github.com/RamonRDR/git-study-guide/issues/new?template=private-contact-request.es.md) solo para solicitar canal; la issue es PÚBLICA. No incluir nombres, detalles del incidente, evidencia, capturas, datos de contacto ni información sensible. Si incluso la solicitud pública expone a alguien, no publicar; usar herramientas de denuncia de GitHub para abuso. En el eventual canal privado compartir solo contexto y evidencia relevantes. Confidencialidad de mejor esfuerzo, no absoluta.

## Aplicación

El mantenedor evalúa contexto, impacto, repetición y seguridad. Medidas proporcionales pueden incluir aclaración, retirada de material dañino, advertencia, restricción temporal, exclusión permanente o escalamiento a GitHub o autoridades competentes. Denuncias incompletas de buena fe no se castigan; denuncias abusivas intencionales y represalias pueden infringir la política. Si el mantenedor está implicado, usar denuncia independiente de GitHub en vez de depender solo de él. Sin plazo de respuesta garantizado.
