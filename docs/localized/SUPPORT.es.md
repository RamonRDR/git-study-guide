# Guía de soporte

[English](../../SUPPORT.md) · [Português](SUPPORT.pt-BR.md) · [Español](SUPPORT.es.md)

## Elija el canal adecuado

- [Pregunta de aprendizaje](https://github.com/RamonRDR/git-study-guide/issues/new?template=learning-question.es.md): Pregunte sobre una lección publicada.
- [Error de contenido o ejemplo](https://github.com/RamonRDR/git-study-guide/issues/new?template=bug-report.es.md): Informe un problema reproducible sin impacto de seguridad.
- [Sugerencia de contenido](https://github.com/RamonRDR/git-study-guide/issues/new?template=content-suggestion.es.md): Proponga mejora educativa enfocada.
- [Mejora de traducción](https://github.com/RamonRDR/git-study-guide/issues/new?template=translation-improvement.es.md): Corrija significado o claridad entre idiomas.
- [Solicitud de contacto privado (issue pública)](https://github.com/RamonRDR/git-study-guide/issues/new?template=private-contact-request.es.md): Solicite solo un canal privado; no divulgue datos sensibles.

Usar política de seguridad y código de conducta para asuntos sensibles. No publicar información privada. Las preguntas pueden ser EN, PT-BR o ES; conservar identificadores técnicos exactos.

## Qué cubre el soporte

Lecciones publicadas, reproducción de ejemplos, enlaces rotos, traducciones, requisitos de contribución y sugerencias alineadas a la hoja de ruta. Informar ruta, comportamiento esperado y observado, ejemplo ficticio mínimo, versión Git/SO/shell y checks intentados cuando proceda. Nunca enviar repos privados ni credenciales.

## Límites

Soporte comunitario de mejor esfuerzo; sin respuesta, implementación, urgencia, recuperación de cuenta, depuración de proyectos ajenos, realización de tareas, mentoría individual ni soporte oficial garantizados. Usar canales oficiales para problemas de cuenta. Issues pueden cerrarse por duplicidad, falta de reproducción segura, contenido sensible o fuera de alcance. Se admite seguimiento respetuoso.

- [Guía de contribución](CONTRIBUTING.es.md)
- [Política de seguridad](SECURITY.es.md)
- [Código de conducta](CODE_OF_CONDUCT.es.md)
