# Identidade visual V1

[English](README.md) · [Português](README.pt-BR.md) · [Español](README.es.md)

Aprovada pelo mantenedor na conversa de finalização de 28/11/2026. Símbolo educacional original, acento Git laranja, hexágono cyan compartilhado, chaves de código e livro aberto. Não representa logo oficial do Git nem endosso. Os 22 exports SVG/PNG aprovados são preservados byte a byte; seis SVGs de idioma e Python são copiados do Python Study Guide v2.0.0. Fontes editáveis, instruções de geração, pranchas e exports estão arquivados no Drive. Fontes tipográficas não são distribuídas; Inter é SIL OFL 1.1. Assets originais cobertos pela licença MIT do repositório; direitos de terceiros permanecem intactos. Variantes clara, escura e monocromáticas disponíveis. Preferir símbolo a partir de 64 px; tamanhos menores perdem detalhes. Card estático em inglês; localização web é tarefa separada. Renderização GitHub desktop/mobile e destinos externos ao vivo ainda requerem inspeção.
