# Visual identity V1

[English](README.md) · [Português](README.pt-BR.md) · [Español](README.es.md)

Approved by the maintainer in the finalization conversation on 28 November 2026. Original educational symbol, Git-orange accent, shared cyan hexagon, code braces and open book. No official Git logo or endorsement. The 22 approved SVG/PNG exports are preserved byte-for-byte; six language and Python badge SVGs are copied from Python Study Guide v2.0.0. Sources, generation instructions, review sheets and exports are archived in Drive. Fonts are not distributed; Inter is SIL OFL 1.1. Original assets are covered by the repository MIT license; third-party rights remain unaffected. Light and dark/monochrome symbol variants are supplied. Use the symbol at 64 px or larger when possible; small marks lose detail. Static card is English; web localization is a separate task. GitHub desktop/mobile render and live external destinations still require inspection.
