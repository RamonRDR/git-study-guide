Try first, consult the public solutions afterward. Quizzes use exact choices; interviews and mocks require honest self-assessment. Challenges use only fresh disposable local repositories and fixed state checks, not automatic execution of learner commands. All records form an internal pilot, not the final Learning Hub contract.

## Foundation assessment

ID: mock-easy

**Difficulty:** easy

**Prerequisites:** [practical-projects/01-my-first-repository](../../practical-projects/01-my-first-repository/README.md)

Complete the referenced questions and one practical challenge without consulting solutions. Record choices, state evidence and interview answers before grading yourself.

**Time (min):** 35

**Included records:** quiz-snapshot, quiz-add, quiz-diff, quiz-config, challenge-first-commit, interview-version-control, interview-three-states

**Hints:**

- Use the prerequisite only after a first attempt; inspect state before any destructive operation.
- If stuck, use the individual record hints and record which hints were needed.

**Rubric:**

- Quizzes: one point per correct choice, maximum four.
- Challenge: one point if all final state checks pass; one point for safe execution and required intermediate evidence. No point for an unmet criterion.
- Interviews: one point per met criterion, maximum four across two questions.

**Explanation:** The maximum is ten points: four quiz answers, two practical points and four interview rubric points. Report each part separately; this is a self-assessment, not certification or AI grading.
