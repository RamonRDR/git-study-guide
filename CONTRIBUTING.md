# Contributing to Git Study Guide

[English](CONTRIBUTING.md) · [Português](docs/localized/CONTRIBUTING.pt-BR.md) · [Español](docs/localized/CONTRIBUTING.es.md)

## Before changing anything

Read the constitution, roadmap and instructions; search existing issues, describe one improvement and agree scope for substantial changes. Anyone may propose changes through a fork and PR; only authorized contributors can write to the upstream repository. Never assume merge permission.

## Contribution workflow

1. Start from current upstream main in a focused branch (for example `docs/branch-explanation`).
2. Make original, small changes; use descriptive English commit messages such as `docs: clarify branch references`.
3. Update all EN/PT-BR/ES documents together, preserve paths and code identifiers.
4. Verify sources, relative links, terminology, prerequisites and examples. Run only safe tests in disposable repos, report commands, results and omissions.
5. Open PR with scope, issue, evidence, AI assistance and risks; address feedback and verify latest revision.
6. Maintainer explicitly approves squash merge; never bypass protections.

## Educational and technical quality

Explain what, why, use/avoid, effects, risk and recovery before practice. Teach beginners without unexplained terms. Prefer official Git/hosting documentation and original examples. Separate native Git from GitHub/GitLab. Identify version, OS, shell and prerequisites when relevant. No private material, secrets or proprietary examples. Do not execute destructive commands on the guide. CI is planned for Sprint 02; do not list nonexistent commands as passing. Later use documented repository checks and allowlisted examples.

## AI and licensing

Disclose AI assistance and verify all material personally; do not send unreviewed generated content. By contributing, permit distribution under the repository MIT license; preserve copyright and compatible attribution. If ownership or permission is uncertain, do not submit. Individual credit remains recorded in Git and PR history.
