## Qué es y por qué

Linux es kernel, núcleo de sistema operativo. Linus Torvalds inició Linux en 1991. Desde 2002 desarrolladores del kernel usaron BitKeeper, sistema distribuido propietario de control de versiones (VCS). Acuerdo de uso gratuito terminó en 2005, y Torvalds y otros colaboradores desarrollaron Git para el kernel. Objetivos incluían velocidad, trabajo distribuido, ramas paralelas y proyecto grande. Git no es Linux y funciona en Windows, Linux y macOS.

## Práctica

Cronología: 1991 inicio Linux; 2002 kernel usa BitKeeper; 2005 inicio Git. Razones importan más que fechas.

En proyecto ficticio de traducción, uno revisa inglés y otro español. Ambos registran historial local independiente e integran al conectar. Sin comandos aquí.

## Errores comunes y seguridad

No confunda Git con plataformas posteriores. Desarrollo distribuido no elimina coordinación ni conflictos.
