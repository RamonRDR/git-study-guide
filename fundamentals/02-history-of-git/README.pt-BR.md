## O que é e por quê

Linux é kernel, núcleo de sistema operacional. Linus Torvalds iniciou Linux em 1991. A partir de 2002 desenvolvedores do kernel usaram BitKeeper, sistema distribuído proprietário de controle de versão (VCS). Acordo de uso gratuito terminou em 2005, e Torvalds e outros colaboradores desenvolveram Git para o kernel. Objetivos incluíam velocidade, trabalho distribuído, branches paralelas e projeto grande. Git não é Linux e funciona em Windows, Linux e macOS.

## Prática

Linha do tempo: 1991 início Linux; 2002 kernel usa BitKeeper; 2005 início Git. Razões importam mais que datas.

Em projeto fictício de tradução, um revisa inglês e outro espanhol. Ambos registram histórico local independente e integram ao conectar. Sem comandos aqui.

## Erros comuns e segurança

Não confunda Git com plataformas posteriores. Desenvolvimento distribuído não elimina coordenação ou conflitos.

## Exercício e autocorreção

Explique por que histórico local importa sem rede. Dica: commits locais funcionam. Passe se distinguir Linux (kernel), BitKeeper (VCS anterior) e Git (VCS distribuído criado em 2005).
